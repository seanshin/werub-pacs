PART 1 · 시작하기

1개요

WeRU.B PACS는 중소 병원/클리닉이 도입할 수 있는 웹 기반 PACS입니다. DICOM 영상의 수신·저장·검색·판독·배포와 의료 AI 분석을 하나의 시스템에서 처리합니다.

🖥️ 웹 뷰어

설치 없이 브라우저에서 2D/MPR/MIP/3D 판독. 측정·주석·핵심영상(KOS).

📥 영상 수집

관리자 업로드·환자 포털·키오스크·외부 PACS Q/R·DICOM 전송(DIMSE/DICOMweb).

✅ 비표준 검증

비표준 DICOM 자동 검증·수정(JPEG 밀도/Pixel Spacing 교차검증 등 24규칙, 15개 자동수정).

🧠 의료 AI

모달리티별 추론·선제 스크리닝·거버넌스. 결과는 참고용(SaMD 면책).

📝 판독 리포트

템플릿 기반 판독문·서명·PKI 전자서명·PDF 배포.

🏥 HIS/RIS 연동

SSO 로그인, 오더 동기화, HL7 v2, 워크리스트(MWL/MPPS).

PART 2 · 작업 흐름 (업무 시나리오)

5전체 파이프라인 한눈에 보기

한 검사가 들어와 환자에게 결과가 전달되기까지의 큰 흐름입니다. 각 단계는 아래 시나리오(6장~)에서 상세히 다룹니다.

검사 오더→ 촬영→ 영상 수신→ 자동 검증·정규화→ 선제 AI→ 배정→ 판독→ 서명→ 결과 배포

노랑 단계는 시스템이 자동 처리합니다(사람 개입은 예외 시).

방사선사
오더 확인 → 촬영(MWL/MPPS) → 업로드/수신 확인 → (필요시) 정규화·재촬영
시스템
DICOM 자동 검증·수정 → 선제 AI 스크리닝 → (규칙 시) 자동 배정·프리페치
판독의
판독 큐 → 뷰어 검토 → 판독문 작성·서명 → 긴급 시 통보
임상의
내 환자에서 결과 확인 → 영상/리포트 열람 → 추가 검사·협진 요청

6작업 흐름 ① 표준 판독 판독의

목적 배정된 검사를 열어 판독문을 작성·서명하고 의뢰자에게 결과를 전달합니다.

판독 큐→ 검사 선택→ 뷰어 검토→ prior 비교→ 판독문 작성→ 서명→ 의뢰자 알림
  1. 판독 큐 진입 — 상단 판독 메뉴. 긴급/STAT 검사는 빨갛게 강조 표시됩니다.판독
  2. 검사 열기 — 판독 보기(통합 화면) 또는 뷰어 열기(WeRU.B). 통합 화면은 영상·환자정보·판독문·AI를 한 화면에 보여줍니다.
  3. 영상 검토 — 뷰어에서 창조절(W/L)·확대·측정. 필요한 슬라이스는 핵심영상(KOS)으로 마킹.
  4. 비교(prior) — 직전 검사가 있으면 나란히 비교(프리페치로 빠르게 로딩).
  5. AI 참고 — AI 패널에서 분석 실행, 결과를 판독문 초안으로 불러오기(참고용).
  6. 판독문 작성 — 소견(Findings)·결론(Impression)·권고 입력. 템플릿으로 표준 문구 삽입.
  7. 임시 저장 / 서명 — 작성 중엔 임시 저장, 완료 시 서명(최종). 전자서명 연동 시 PDF에 PKI 서명.
  8. 통보 — 서명 즉시 의뢰자에게 알림. 긴급 소견은 별도 긴급 통보.완료
서명 후 정정

최종 서명 리포트는 법적 기록입니다. 정정은 추가 판독(새 버전)으로 기록되며, 두 사람이 동시에 서명하려 하면 시스템이 충돌을 자동 차단합니다.

관련 메뉴: 17. 판독 · 18. 뷰어 · 20. 템플릿 · 34. 전자서명

7작업 흐름 ② 방사선사 일과 방사선사

목적 검사를 촬영하고 영상을 정상적으로 시스템에 등록합니다.

1. 준비
워크리스트에서 오늘 검사 확인 — 장비는 MWL로 자동 조회
2. 촬영
검사 진행 → 장비가 진행상태 보고(MPPS) → 영상이 PACS로 전송(C-STORE)
3. 확인
수신 모니터에서 영상 도착·매수 확인. 외부 영상은 업로드/외부연동 Q/R
4. 품질
비표준 영상은 시스템이 자동 검증. 정규화 → 검토에서 수정 제안 승인
5. 예외
재촬영 요청이 오면 재촬영에서 승인 → 재촬영 → 완료 처리
매수가 안 맞을 때

수신 모니터에서 누락이 보이면 장비 재전송 또는 외부연동 Q/R로 보완하세요. 비표준으로 안 열리면 27장(DICOM 이슈)을 확인합니다.

관련 메뉴: 22. 워크리스트 · 25. 수신 모니터 · 24. 업로드 · 28. 정규화

8작업 흐름 ③ 임상의(의뢰의) 임상의

목적 내가 의뢰한 검사의 영상·판독 결과를 확인합니다.

  1. 내 환자 메뉴 진입 — 본인 의뢰분만 표시(판독 상태 포함).임상의
  2. 판독 완료 알림(🔔)이 오면 해당 환자 클릭
  3. 리포트 보기(소견/결론) 또는 PDF로 출력
  4. 필요 시 영상 썸네일 → 뷰어 열기로 영상 직접 확인
  5. 추가 검사가 필요하면 재촬영 요청 또는 협진 의뢰
접근 범위

임상의는 본인 의뢰분만 열람합니다. 권한 밖 환자가 필요하면 관리자/판독 책임자에게 문의하세요.

관련 메뉴: 32. 내 환자 · 29. 재촬영

9작업 흐름 ④ 응급/STAT 판독의 방사선사

목적 응급 검사를 최우선으로 판독·통보합니다.

STAT 오더→ 우선 촬영→ 선제 AI 긴급 알림→ 응급 큐 최상단→ 즉시 판독→ 긴급 통보
  • 응급 메뉴에서 STAT/긴급 검사만 모아 봅니다(일반 큐보다 상위 정렬).
  • AI 선제 스크리닝이 긴급 소견(예: 출혈/기흉 의심)을 감지하면 판독의에게 즉시 알림(참고용).
  • 판독 후 긴급 소견 통보 — 의뢰자/당직에게 즉시 전달, 통보 시각이 기록됩니다.

관련 메뉴: 응급 영상 보드 · 30. AI · 21. SLA

10작업 흐름 ⑤ 재촬영 판독의 임상의 방사선사

판독의/임상의
재촬영에서 요청 등록 — 사유/범주(체위·움직임·불완전)/긴급도 입력 (상태: requested)
방사선사/관리자
검토 후 승인(approved) 또는 거부(rejected)
방사선사
일정 확정(scheduled) → 재촬영 → 완료(completed)

관련 메뉴: 29. 재촬영

11작업 흐름 ⑥ 협진 · 세컨드오피니언 판독의

협진 요청→ 토큰 링크 발송→ 외부 전문의 동의→ 영상 열람·의견 제출→ 의견 회수·알림
  1. 협진 또는 세컨드오피니언에서 대상 검사·질의 입력 후 요청 생성
  2. 외부 전문의에게 만료되는 1회용 토큰 링크(이메일) 발송
  3. 외부 전문의는 의뢰 포털에서 로그인 없이 동의 후 영상 확인·의견 제출
  4. 제출되면 요청자(판독의)에게 알림, 의견이 시스템에 회수됨
안전 공유

토큰은 만료·1회용이며 접근 내역은 감사 로그에 남습니다.

관련 메뉴: 31. 협진

12작업 흐름 ⑦ 환자 영상 업로드 → 승인 방사선사 관리자

토큰 발급→ 환자 업로드(포털/키오스크)→ 승인 큐 대기→ 매칭·중복 확인→ 승인·저장
  1. 병원이 환자에게 1회용 업로드 토큰 발급
  2. 환자가 환자 포털 또는 접수 데스크 키오스크에서 CD/USB 영상 업로드
  3. 업로드 영상은 승인 큐(/upload-queue)에 대기
  4. 관리자가 환자 매칭·중복 여부 확인 후 승인(저장) 또는 반려
대용량

업로드 용량 상한이 있습니다. 매우 큰 검사는 나눠 올리거나 외부 PACS Q/R를 이용하세요.

관련 메뉴: 24. 업로드·수집 · 33. 환자 포털·키오스크

13작업 흐름 ⑧ DICOM 품질 이슈 처리 관리자 방사선사

영상 수신→ 자동 검증(24규칙)→ 이슈 발견→ 자동수정(백업)→ 불가 시 미수정 플래그→ 검토·필요시 롤백
  • 5분 주기 자동 검증이 신규 영상을 점검(예: JPEG 밀도 vs Pixel Spacing 불일치, UID/VR/Transfer Syntax 오류).
  • 자동수정 가능한 15개 규칙은 원본 백업 후 보정(연쇄 수정 포함). 잘못되면 실제 원본으로 롤백(원본 바이트 복원).
  • 자동수정 불가 이슈는 미수정 상태로 플래그되어 사람이 검토합니다.
  • 설정에서 규칙 on/off·에러 문구·모달리티별 렌더 조정.
측정값이 이상할 때

거리/면적 측정이 틀리면 Pixel Spacing 비표준 가능성. DICOM 이슈 센터에서 해당 규칙을 확인·적용하세요.

PART 3 · 판독 업무

16대시보드 전체

로그인 후 첫 화면. 30초마다 자동 갱신됩니다.

  • 긴급 배너 — 긴급 판독 건이 있으면 상단에 표시 → 판독 시작 바로가기
  • 핵심 지표 카드 — 판독 대기(+SLA 위반/경고), 오늘 완료, 오늘 워크리스트(모달리티별), AI 분석(완료/긴급소견)
  • 운영 카드 — 워크리스트(MWL/MPPS), SLA(7일), 재촬영, HIS 연동, 스토리지
  • 품질 카드 — DICOM 이슈(심각도별), 자동수정율, 영상 출처, 업로드 큐
  • 판독 대기 목록 — 상위 15건(SLA 표시·뷰어/판독 버튼), 전체 보기로 판독 큐 이동

17판독 판독의 전공의

판독 큐

각 행에서 뷰어 열기 또는 판독 보기로 진입합니다. 상태 필터: 전체 / 판독 대기 / 작성 중 / 예비 판독 / 완료. 긴급·STAT 검사는 행이 빨갛게 강조 표시됩니다(정렬 순서는 서버 기준).

판독 보기(통합 화면)

/reading/view — 환자정보·판독문 편집기·AI 결과를 한 화면에서. 영상은 뷰어 열기 버튼으로 별도 창에서 보거나, single 모드에서 뷰어가 화면에 임베드됩니다(썸네일 목록은 아님).

  • 편집기 — 소견·결론·권고 입력, 템플릿 삽입, 자동 임시저장
  • AI 초안 반영 — 페이지를 연 뒤 뷰어 등에서 AI 초안이 작성되면 약 2초 폴링으로 편집기에 반영(검토 후 수정)
  • 서명 — 최종 서명 시 확정·의뢰자 알림
  • 외부 전자서명 — PKI 서명, 보증 배지(HSM/소프트웨어). HIS 세션이 있어야 동작 (34장)
  • 이동 — Q 판독 큐로, N(다음 Study)으로 다음 미판독 검사로 연속 진행 (※이전 이동은 없음)

판독 통계

/reading/stats(TAT)·/reading/residents(전공의 성과)에서 소요시간·생산성 확인.

18WeRU.B 뷰어

OHIF v3 / Cornerstone3D 기반. 상단 WeRU.B ↗ 또는 판독 큐 뷰어 열기로 실행.

레이아웃

1×1·2×2 등 분할, MPR, 3D 볼륨(VRT). 재구성 가능한 CT/MR은 열자마자 MPR 3면이 자동 적용되고, 단면 검사는 1×1로 열립니다. (MIP는 MPR 슬랩 두께로 표현)

이전검사 비교

툴바 이전검사 버튼 또는 P — 같은 환자의 최신 이전 검사를 찾아 나란히 비교 화면으로 한 번에 전환. 이전 검사가 없으면 안내만 표시.

창 조절 W/L

모달리티별 프리셋(폐·뼈·복부 등, 단축키 1~5), 드래그로 밝기/대조.

측정·주석

길이·각도·ROI·픽셀값. 저장하면 새로고침 후 복원(재수화)됩니다.

핵심영상 KOS

중요 슬라이스 마킹 → 판독문/공유 첨부.

AI 패널

AI 분석 실행·오버레이·판독문 전송.

리포트 패널

뷰어 내 판독문 작성·서명(판독 동기화).

3D VRT

레이아웃 선택기의 3D 항목(3D 메인 / MPR + 3D / 3D 4분할 / 3D 단독 / 3D 주화면)으로 진입합니다. 3D 진입 시 "참고용 3D 렌더링 — 측정은 MPR에서" 안내가 표시되고 3D 화면에서는 측정 도구가 잠겨 측정 오류를 방지합니다. 렌더링 프리셋은 한국 임상 기준 13종(뼈·연부조직·폐·심장·관상동맥·간혈관 등, 한글 표기)으로 정리되어 있습니다. 재구성 가능한 다중 영상 시리즈에서만 활성화됩니다.

⚑응급 영상 보드 (ER 보드) 판독의 임상의 방사선사

  • 카드 정보 — 상태(대기·작성중·예비·완료) 배지, STAT·긴급 태그(빨강·깜빡임), 환자·모달리티·검사명, 미판독 대기시간(30분↑ 주황, 60분↑ 빨강·깜빡임), 배정 판독의, 뷰어 열기. 완료/예비 검사는 결론(impression)을 카드에 미리 보여줍니다.

참고

정렬 순서는 서버(보드 API) 기준이며, 화면은 STAT/긴급/대기시간을 색으로 강조합니다. 응급실 전용 계정(예: er.doctor)으로도 접근할 수 있습니다.

부록 D. FAQ · 문제 해결

Q. 메뉴가 안 보여요.

A. 역할에 따라 필터링됩니다. 필요한 메뉴는 관리자에게 역할 부여를 요청하세요.

Q. 뷰어에서 영상이 안 열려요.

A. 새로고침 후 재시도. 비표준 영상은 DICOM 이슈/정규화 처리가 필요할 수 있습니다(13·27·28장).

Q. 측정값이 이상해요.

A. Pixel Spacing 비표준 가능성. DICOM 이슈 센터의 자동 검증/수정을 확인하세요.

Q. AI 결과를 그대로 진단에 써도 되나요?

A. 아니요. 참고용(진단 보조)이며 최종 판단은 판독의입니다.

Q. 로그인이 자꾸 풀려요.

A. 30분 유휴 시 자동 로그아웃됩니다.

Q. 외부 병원 영상을 가져오려면?

A. 외부 연동(26장) Q/R 또는 환자 포털/키오스크 업로드(12·33장).

Q. 판독을 잘못 서명했어요.

A. 추가 판독(정정 기록)으로 보완. 판독 책임자와 상의하세요.

Q. 검사가 배정이 안 됐어요.

A. 배정(19장)에서 수동 배정하거나 자동 배정 규칙을 확인하세요.
