## 2. 개선 기능 명세

### 2.1 로그인/로그아웃 + 사용자 정보

**Nav 우측에 사용자 정보 + 로그아웃 버튼 표시**

```
┌────────────────────────────────────────────────────────────────────┐
│ OpenPACS  대시보드  판독  워크리스트  템플릿  사용자  감사로그  AI     │
│                                                                    │
│                           뷰어↗  API↗  👤 김영상(radiologist) [로그아웃]│
└────────────────────────────────────────────────────────────────────┘
```

- 로그인 시 사용자명 + 역할 표시
- 로그아웃 클릭 → localStorage 토큰 삭제 → 로그인 화면으로
- 세션 만료(401) 시 자동 로그아웃 + 알림

### 2.2 날짜 포맷 통일

| 현재 | 개선 |
|------|------|
| 20000101 | 2000-01-01 |
| 19841013 | 1984-10-13 |
| 20260512 | 2026-05-12 |

```typescript
function formatDate(dicomDate: string): string {
  if (!dicomDate || dicomDate.length !== 8) return dicomDate || '-';
  return `${dicomDate.slice(0,4)}-${dicomDate.slice(4,6)}-${dicomDate.slice(6,8)}`;
}
```

### 2.3 환자명 정리

| 현재 | 개선 |
|------|------|
| `CompressedSamples^CT1` | `CompressedSamples CT1` |
| `1001^6657^ISPY1` | `1001 6657 ISPY1` |
| `OB^^^^` | `OB` |
| `-` (빈 값) | `(이름 없음)` |

```typescript
function formatPatientName(name: string): string {
  if (!name || name === '-') return '(이름 없음)';
  return name.replace(/\^+/g, ' ').replace(/\s+/g, ' ').trim();
}
```

### 2.4 모달리티 컬러 배지

모달리티별 색상 구분으로 빠른 시각적 인식:

| 모달리티 | 색상 | 배지 |
|---------|------|------|
| CR/DX | 파랑 | `bg-blue-100 text-blue-700` |
| CT | 보라 | `bg-purple-100 text-purple-700` |
| MR | 초록 | `bg-green-100 text-green-700` |
| US | 노랑 | `bg-yellow-100 text-yellow-700` |
| SR | 회색 | `bg-gray-100 text-gray-600` |

### 2.5 대시보드 카드 강조

- **판독 대기 > 0**: 노란 배경 + 깜빡임
- **긴급 > 0**: 빨간 배경 + 강조
- **오늘 완료**: 초록 텍스트

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 판독 대기  │ │ 긴급      │ │ 오늘 판독  │
│   ⚠️ 3    │ │  🔴 1    │ │  ✅ 5    │
│ (경고 배경) │ │ (빨간 배경)│ │ (초록)    │
└──────────┘ └──────────┘ └──────────┘
```

### 2.8 판독 큐 — 직접 AI 분석

판독 큐 테이블에서 **바로 AI 분석** 실행 가능:

| 상태 | 환자명 | ... | 검사일 | 액션 |
|------|--------|-----|--------|------|
| 대기 | 홍길동 | ... | 2026-05-12 | [🤖 AI] [판독 ↗] |

"🤖 AI" 클릭 → MedGemma 분석 → 판독문 초안 자동 생성 → 상태 "draft"로 변경

### 2.9 자동 새로고침

- 대시보드: 30초마다 자동 새로고침
- 판독 큐: 15초마다 새 검사 확인
- WebSocket 연동 시 실시간 업데이트 (향후)

### 2.10 검색 기능

대시보드 + 판독 큐에 검색 바 추가:

```
┌─────────────────────────────────────────────┐
│ 🔍 환자명, 환자번호, 검사설명으로 검색...     │
└─────────────────────────────────────────────┘
```

- 환자명: 초성 검색 지원 (ㅎㄱㄷ → 홍길동)
- 실시간 필터링 (입력 시 테이블 즉시 갱신)

### 6.2 추가 연동 대상 (P0~P1)

#### 비교 판독 보고서 (P0)
```
POST /api/v1/ai/compare-report
→ AI Server: POST /api/vision/medical/report
→ 현재+이전 영상 → 구조화된 비교 판독문 자동 생성
```

#### 의료 모델 목록 (P1)
```
GET /api/v1/ai/medical-models
→ AI Server: GET /api/vision/medical/models
→ Admin Portal AI 대시보드에 실시간 모델 상태 표시
```

#### SOAP 의무기록 요약 (P1)
```
POST /api/v1/ai/soap-summary
→ AI Server: POST /api/medical/summarize
→ 판독 소견 → SOAP 형식 요약 (Subjective/Objective/Assessment/Plan)
```

#### 감별진단 (P1)
```
POST /api/v1/ai/differential-diagnosis
→ AI Server: POST /api/medical/analyze
→ 증상/소견 → Top 3 감별진단 + ICD-10 코드
```

### 6.3 Admin Portal AI 페이지 개선

현재:
- 등록된 모델 목록 (DB)
- 추론 통계

추가 필요:
- **AI Server 실시간 모델 상태** (GPU VRAM, 로드 상태)
- **의료 영상 분석 이력** (최근 분석 결과 목록)
- **비교 판독 UI** (현재 vs 이전 영상 나란히)
- **SOAP 요약 버튼** (판독문 → SOAP 변환)
- **감별진단 패널** (AI 소견 기반 감별진단 표시)
