## 1. 제품 개요

### 1.1 제품명 및 용도
- **제품명**: WeRU.B PACS (의료영상저장전송장치)
- **용도**: 의료 영상(DICOM)의 저장, 전송, 조회, 표시를 위한 웹 기반 PACS 소프트웨어
- **등급**: 2등급 의료기기 (MFDS)
- **사용 환경**: 병원, 클리닉 등 의료기관

### 1.2 주요 기능
- DICOM 영상 수신/저장/조회 (DIMSE + DICOMweb)
- 웹 기반 영상 뷰어 (2D, MPR, MIP)
- 판독 워크플로우 (워크리스트, 리포트, 템플릿)
- DICOM 비표준 영상 검증/정규화
- QC 기능 (Study 병합/분리, 태그 수정, 익명화)
- AI 보조 진단 연동 (SOAP, 감별진단, 비교판독) — AI 모델 29개 (의료 13종, 범용 16종)
- 감사 로그 및 보안 관리

### 1.3 사용 대상
| 역할 | 주요 업무 | 시스템 권한 |
|------|-----------|-------------|
| 관리자 (ADMIN) | 시스템 설정, 사용자 관리, 감사 로그 | 전체 기능 접근 |
| 영상의학과 전문의 (RADIOLOGIST) | 판독, 리포트 작성, AI 사용 | 판독/리포트/AI |

| 임상의 (PHYSICIAN) | 영상 조회, 리포트 열람, 협진 의뢰 | 조회/리포트 열람/협진 |
| 방사선사 (TECHNOLOGIST) | QC, 검증/정규화, 워크리스트 관리 | QC/검증/워크리스트 |

## 3. 로그인

### 3.1 접속
1. 웹 브라우저에서 `https://<서버주소>/admin` 으로 접속한다.
2. 로그인 화면에서 아이디와 비밀번호를 입력한다.
3. "로그인" 버튼을 클릭한다.

### 3.2 비밀번호 규칙
- 최소 8자 이상
- 영문 대소문자, 숫자, 특수문자 조합
- 90일마다 변경 권장

### 3.3 세션 관리
- Access Token: 1시간 유효 (자동 갱신)
- Refresh Token: 7일 유효
- 비활성 30분 후 자동 로그아웃
- 동시 세션: 최대 3개

### 3.4 로그아웃
- 우측 상단 사용자 메뉴 → "로그아웃" 클릭
- 세션이 즉시 종료되며 로그인 화면으로 이동

## 4. 대시보드

### 4.1 통계 요약
로그인 후 대시보드에서 다음 통계를 확인할 수 있다:
- 전체 Study 수 / 오늘 접수 건수
- Patient 수 / Series 수 / Instance 수
- 저장소 사용량 (GB)
- 시스템 가동 시간 (Uptime)

### 4.2 최근 Study 목록
- 최근 접수된 Study를 날짜순으로 표시
- 환자명, Patient ID, Modality, Study Date, Description 표시
- 모달리티별 색상 배지 (CT: 파랑, MR: 초록, CR: 주황, US: 보라)
- 클릭하면 Study 상세 화면으로 이동

### 4.3 자동 새로고침
- 대시보드는 30초마다 자동 갱신
- 새로운 Study 접수 시 목록 자동 업데이트

## 5. 판독 워크플로우

### 5.1 워크리스트
1. 좌측 메뉴 "워크리스트" 클릭
2. 자신에게 배정된 Study 목록 표시
3. 우선순위별 정렬: Emergency(빨강) > Urgent(주황) > Routine(녹색)
4. 필터: 날짜 범위, 모달리티, 상태(미판독/판독중/완료)

### 5.2 영상 뷰어 열기
1. 워크리스트 또는 Study 목록에서 대상 Study 클릭
2. "뷰어 열기" 버튼 클릭 → WeRU.B Viewer가 새 탭에서 열림
3. 또는 Study 행의 뷰어 아이콘을 직접 클릭

### 5.3 리포트 작성
1. 판독 화면에서 "리포트 작성" 클릭
2. 리포트 유형 선택 (자유 형식 / 구조화 / SOAP)
3. 템플릿 선택 (20개 사전 정의 템플릿):
   - CT: 복부 CT, 흉부 CT, 뇌 CT 등
   - MR: 뇌 MR, 척추 MR, 관절 MR 등
   - CR: Chest PA, Abdomen 등
   - US: 복부 초음파, 심장 초음파 등
4. 소견(Findings), 인상(Impression), 권고(Recommendation) 입력
5. "임시 저장" (Draft) 또는 "최종 확정" (Final) 클릭

### 5.4 AI 보조 기능
- **SOAP 자동 생성**: 리포트 작성 시 "AI SOAP" 버튼 클릭 → 구조화 소견 자동 생성
- **감별진단 제안**: 소견 입력 후 "AI 감별진단" → 가능한 진단 목록 제안
- **비교판독 지원**: 이전 검사와 비교 시 "AI 비교" → 변화 부위 자동 하이라이트

> **주의**: AI 보조 기능은 참고용이며, 최종 판단은 반드시 판독의가 내립니다. AI 결과에는 신뢰도 점수가 표시됩니다.

## 6. 뷰어 사용법 (WeRU.B Viewer)

### 6.1 화면 구성
- **좌측 패널**: 시리즈 목록, 썸네일
- **중앙**: 영상 표시 영역 (1x1, 1x2, 2x2 레이아웃)
- **우측 패널**: 측정 도구, 주석(Annotation)
- **상단 도구모음**: Window/Level, Zoom, Pan, 측정, 주석, 리셋

### 6.2 영상 조작

| 조작 | 마우스 | 단축키 |
|------|--------|--------|
| Window/Level 조절 | 우클릭 드래그 | W |
| 확대/축소 (Zoom) | 스크롤 휠 | Z |
| 이동 (Pan) | 가운데 버튼 드래그 | T |
| 스크롤 (슬라이스 이동) | 스크롤 휠 | ↑↓ |
| 회전 | - | R |
| 좌우 반전 (Flip H) | - | H |
| 상하 반전 (Flip V) | - | V |
| 리셋 | - | Space |
| 전체화면 | 더블 클릭 | F |

### 6.3 측정 도구

| 도구 | 기능 | 단축키 |
|------|------|--------|
| 길이 측정 | 두 점 사이 거리 (mm) | L |
| 타원 면적 | 타원 영역 면적/평균 HU | E |
| 각도 측정 | 세 점 사이 각도 (°) | A |
| ROI (사각형) | 영역 평균/표준편차 HU | O |
| Cobb 각도 | 척추 측만 각도 | C |
| 텍스트 주석 | 자유 텍스트 입력 | N |

### 6.4 프리셋 (Preset)

| 프리셋 | Window | Level | 용도 |
|--------|--------|-------|------|
| Abdomen | 400 | 40 | 복부 CT |
| Lung | 1500 | -600 | 폐 CT |
| Bone | 2000 | 400 | 뼈 CT |
| Brain | 80 | 40 | 뇌 CT |
| Mediastinum | 350 | 50 | 종격동 CT |

### 6.5 MPR/MIP
- MPR (Multi-Planar Reconstruction): 축상면/관상면/시상면 재구성
- MIP (Maximum Intensity Projection): 혈관 등 고밀도 구조 강조
- MPR/MIP는 CT/MR 3D 데이터셋에서 사용 가능

## 7. 관리 기능

### 7.1 사용자 관리 (Admin 전용)
1. 관리 메뉴 → "사용자 관리"
2. 사용자 추가: 아이디, 이름, 비밀번호, 역할 입력
3. 역할 변경: 사용자 선택 → 역할 드롭다운 변경
4. 계정 비활성화: 사용자 선택 → "비활성화" 토글

### 7.2 감사 로그 (Admin 전용)
1. 관리 메뉴 → "감사 로그"
2. 필터: 사용자, 행위(Action), 날짜 범위
3. 내보내기: CSV/JSON 형식 다운로드
4. 기록되는 행위: 로그인, 로그아웃, Study 조회, 리포트 작성/수정, QC 작업, 사용자 관리

### 7.3 DICOM 검증/정규화 (Technologist 이상)
1. 관리 메뉴 → "검증/정규화"
2. Study 선택 → "DICOM 검증" 실행
3. 검증 결과 확인 (표준 태그 누락, JPEG 밀도 불일치 등)
4. 비표준 태그 → "정규화" 실행으로 자동 보정

### 7.4 QC 기능 (Technologist 이상)
- **Study 병합**: 잘못 분리된 Study 2개를 1개로 합침
- **Study 분리**: 잘못 합쳐진 Study를 2개로 나눔
- **태그 수정**: DICOM 태그 직접 편집 (Patient Name, Study Description 등)
- **익명화**: 연구용 데이터 생성 시 환자 식별정보 제거

## 9. 문제 해결 (Troubleshooting)

| 증상 | 원인 | 해결 방법 |
|------|------|-----------|
| 로그인 실패 | 비밀번호 오류 5회 → 계정 잠금 | 30분 후 재시도 또는 관리자에게 잠금 해제 요청 |
| 영상 로딩 느림 | 네트워크 대역폭 부족 | 100Mbps 이상 네트워크 확인 |
| 뷰어 빈 화면 | 브라우저 캐시 | Ctrl+Shift+R 으로 강제 새로고침 |
| 측정값 이상 | JPEG 밀도 불일치 | "DICOM 검증" 실행 후 "정규화" 수행 |
| DICOM 수신 실패 | AE Title 불일치 | 송신측 AE Title = OPENPACS 확인 |
| 리포트 저장 실패 | 네트워크 일시 중단 | 재시도, 임시 저장 확인 |

## 10. 안전 주의사항

1. **판독용 모니터**: 의료 판독에는 DICOM GSDF 보정된 전용 모니터를 사용하십시오.
2. **AI 보조 기능**: AI 결과는 참고용이며, 모든 진단은 의사가 최종 확인합니다.
3. **개인정보 보호**: 화면을 공유하거나 촬영하지 마십시오. 로그아웃 후 자리를 비우십시오.
4. **비밀번호 관리**: 비밀번호를 타인과 공유하지 마십시오.
5. **데이터 백업**: 중요 리포트는 최종 확정 전 임시 저장을 활용하십시오.
