## 별도 규제 트랙 — EMR 인증제 (한국보건의료정보원)

본 README의 위 문서들은 **식약처(MFDS) 의료기기(PACS 2등급) 인증** 트랙이다.
**전자의무기록시스템(EMR) 인증제**(의료법 §23조의2, 한국보건의료정보원)는 **별개 제도**로,
PACS는 직접 대상이 아니나 **인증 EMR의 진료정보교류(영상)·보안성 요건을 뒷받침**한다.

## 개발-인허가 병행 관리 원칙

```
개발 커밋 발생 시:
  1. Git commit (코드)
  2. DHF 변경관리 이력 추가 (CHG-NNN)
  3. 해당 기술문서 업데이트 (SRS/SDS/V&V)
  4. 위험 분석 영향 여부 확인

인허가 문서 변경 시:
  1. 문서 수정
  2. README.md 상태 테이블 업데이트
  3. Git commit (docs/regulatory/)
  4. DHF 문서 목록 업데이트
```
