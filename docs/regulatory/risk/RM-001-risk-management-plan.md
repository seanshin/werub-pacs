# RM-001 위험관리 계획서 (Risk Management Plan)

| 등급 | 2등급 의료기기 |

## 1. 목적

WeRU.B PACS 소프트웨어 의료기기의 전체 수명주기에 걸친 위험관리 활동을 계획하고, ISO 14971에 따른 위험관리 프로세스를 정의한다.

## 2. 적용 범위

- 의도된 사용: 의료 영상(DICOM) 저장, 조회, 표시
- 사용 환경: 병원/클리닉 내 네트워크 환경
- 사용자: 방사선과 전문의, 방사선사, 임상의, IT 관리자
- 제외: 치료 결정 자동화 (AI는 보조 도구로만 사용)

## 3. 위험 허용 기준 (Risk Acceptability Criteria)

### 3.1 심각도 (Severity)

| 등급 | 설명 | 예시 |
|------|------|------|
| S1 (무시) | 불편 수준 | UI 표시 지연 |
| S2 (경미) | 일시적 기능 제한 | 검색 결과 누락 (재시도 가능) |
| S3 (중등) | 진단 지연 가능 | 영상 표시 오류, 측정값 부정확 |
| S4 (심각) | 오진 가능성 | 환자 영상 혼동, 데이터 손실 |
| S5 (치명) | 생명 위협 | 해당 없음 (PACS는 진단 보조) |

### 3.2 발생 확률 (Probability)

| 등급 | 빈도 | 기준 |
|------|------|------|
| P1 | 거의 불가능 | < 1/100,000 사용 |
| P2 | 희박 | 1/10,000 ~ 1/100,000 |
| P3 | 가끔 | 1/1,000 ~ 1/10,000 |
| P4 | 빈번 | 1/100 ~ 1/1,000 |
| P5 | 자주 | > 1/100 |

### 3.3 위험 매트릭스

| | P1 | P2 | P3 | P4 | P5 |
|---|---|---|---|---|---|
| S5 | M | H | H | H | H |
| S4 | L | M | H | H | H |
| S3 | L | L | M | M | H |
| S2 | L | L | L | L | M |
| S1 | L | L | L | L | L |

- **H (High)**: 허용 불가 — 반드시 저감 조치 필요
- **M (Medium)**: 조건부 허용 — 합리적 저감 조치 수행
- **L (Low)**: 허용 — 모니터링

## 4. 위험관리 활동

### 4.1 위험 식별
- 의도된 사용 및 오사용 분석
- DICOM 데이터 흐름 분석 (수신 → 저장 → 조회 → 표시)
- 소프트웨어 장애 모드 분석 (FMEA)
- 사이버보안 위협 분석

### 4.2 위험 분석 (RM-002)
- 위험원(Hazard) 식별
- 위험 상황(Hazardous Situation) 도출
- 심각도 × 발생확률 평가

### 4.3 위험 통제
- 설계에 의한 안전 (Inherent Safety)
- 보호 조치 (Protective Measures)
- 사용자 정보 제공 (Information for Safety)

### 4.4 잔여위험 평가 (RM-003)
- 통제 조치 후 잔여위험 재평가
- 전체 잔여위험의 수용 가능성 판단

### 4.5 생산 및 생산 후 정보
- 사용자 불만 모니터링
- CAPA 연계 (SOP-008)
- 정기 위험 재평가 (연 1회)

## 5. 위험관리 조직

| 역할 | 책임 |
|------|------|
