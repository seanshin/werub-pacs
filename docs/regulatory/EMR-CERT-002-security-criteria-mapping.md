# EMR-CERT-002 — EMR 인증 보안성 항목별 매핑 (S001–S013)

**상위**: [EMR-CERT-001](EMR-CERT-001-emr-certification-mapping.md) · **조사일**: 2026-06-14
**출처**: EMR 표준프레임워크 보안성 참조모듈(emrcert.mohw.go.kr) — 항목코드·명칭 추출
**상태**: 보안성 항목별 매핑 완료(초안). 상호운용성(C-코드) 항목은 공식 페이지 추출 실패 → 보류

> **재확인**: EMR 인증 대상은 EMR 제품(HospitalRun)이며 PACS는 직접 대상 아님. 본 매핑은
> **OpenPACS가 동일 보안 기준을 만족하는지** 자가점검 — 연동 환경 보안 증빙·내부 강화용.
> 항목 수는 출처별 상이(1주기 86 / 2주기 통합 정비 / 참조모듈 S001~S013) — **S-목록은 참조모듈 기준**.

### 요약 (2026-06-14 — 갭 전량 해소)
- **충족(✅) 11 / 확인필요(🟡) 2(운영) / 하드갭 0**
- **S005 해소** ✅: 안전한 암호 알고리즘에 **AES 포함** → OpenPACS AES 인정.
- **S011 충족** ✅: **경량 전자서명 구현**(Ed25519 내용서명, 위변조 탐지, 공인 불요). config-gated.
- **확인필요(운영)**: S001(백업 cron 가동), S003(NTP 증빙) — 코드 아닌 운영 조치.
