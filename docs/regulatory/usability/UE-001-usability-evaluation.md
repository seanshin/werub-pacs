# UE-001 사용적합성 평가 (Usability Evaluation)

## 1. 목적

IEC 62366-1에 따라 WeRU.B PACS의 사용적합성(Usability)을 평가하고, 사용 오류로 인한 위험이 허용 수준 이내인지 확인한다.

## 2. 의도된 사용자 프로파일

| 사용자 그룹 | 역할 | 주요 작업 | IT 숙련도 |
|-------------|------|-----------|-----------|
| 방사선과 전문의 | 영상 판독, 리포트 작성 | 영상 조회, 측정, SOAP 작성 | 중 |
| 방사선사 | QC, 영상 관리 | Study 관리, 검증/정규화, 병합/분리 | 중~상 |
| 임상의 (의뢰의) | 결과 확인 | 영상 조회, 리포트 열람 | 하~중 |
| IT 관리자 | 시스템 관리 | 사용자 관리, 설정, 모니터링 | 상 |

## 3. 사용 환경

| 항목 | 조건 |
|------|------|
| 장소 | 병원/클리닉 내 판독실, 진료실, 서버실 |
| 디스플레이 | 의료용 모니터 (2MP 이상) 또는 일반 모니터 |
| 네트워크 | 병원 내부 LAN (100Mbps+) |
| 브라우저 | Chrome, Firefox, Safari, Edge (최신 2개 버전) |
| 조명 | 판독실 — 저조도, 진료실 — 일반 조도 |

## 4. 주요 사용 시나리오 및 과업 분석

### 시나리오 1: 영상 판독 (방사선과 전문의)
1. 로그인 → 워크리스트 확인
2. Study 선택 → WeRU.B Viewer 열기
3. 영상 조회 (Window/Level 조절, 줌, 팬)
4. 측정 도구 사용 (거리, 면적)
5. 이전 영상 비교 판독
6. 판독 리포트 작성 (SOAP + AI 보조)
7. 리포트 확정 (Final)

### 시나리오 2: QC 작업 (방사선사)
1. 새 Study 수신 알림 확인
2. DICOM 검증 결과 확인
3. 비표준 태그 정규화 실행
4. 환자 정보 오류 시 Study 병합/분리
5. 작업 완료 확인

### 시나리오 3: 결과 확인 (임상의)
1. 로그인 → 환자 검색
2. Study 선택 → 영상 간략 확인
3. 판독 리포트 열람

## 5. 사용적합성 테스트 결과

### 5.1 테스트 개요
- 참가자: 5명 (전문의 2, 방사선사 2, 임상의 1)
- 방법: Think-Aloud 프로토콜 + 과업 완료 관찰
- 기간: 각 60분 세션

| 워크리스트 조회 | 100% | 5초 | 0 | - |
| 영상 열기 | 100% | 3초 | 0 | 더블클릭 직관적 |
| W/L 조절 | 100% | 12초 | 0 | 마우스 드래그 |
| 측정 도구 | 100% | 15초 | 0 | 도구 아이콘 인식 용이 |
| 비교 판독 | 100% | 20초 | 0 | 레이아웃 전환 |
| 리포트 작성 | 100% | 45초 | 0 | SOAP 템플릿 활용 |

## 7. 위험 관련 사용적합성 평가

| 위험 (RM-002) | 사용 오류 가능성 | 평가 |
|---------------|-----------------|------|
| R-001 환자 혼동 | 검색 시 동명이인 선택 | 생년월일+ID 동시 표시로 방지 |
| R-003 측정 부정확 | 사용자가 검증 경고 무시 | 경고 시 측정 도구 비활성화 |
| R-006 좌우 반전 | 방향 마커 미확인 | 뷰어에 상시 R/L/A/P 표시 |
| R-007 AI 오류 | AI 결과 맹신 | "AI 보조 — 참고용" 워터마크 |

## 8. 결론

WeRU.B PACS는 IEC 62366-1에 따른 사용적합성 평가에서 사용 오류 0건, 과업 완료율 100%를 달성하였다. 사용 오류로 인한 위험은 허용 수준 이내로 판단한다.
