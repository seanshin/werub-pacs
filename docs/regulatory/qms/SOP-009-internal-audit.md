# SOP-009 내부감사 절차서 (Internal Audit Procedure)

| 항목 | 내용 |
|------|------|
| 문서 ID | SOP-009 |
| 버전 | 2.0 |
| 작성일 | 2026-05-18 |
| 상태 | 승인 |
| 적용 표준 | ISO 13485:2016 §8.2.4, IEC 62304:2006+A1:2015 |
| 제품명 | WeRU.B PACS |

## 1. 목적

WeRU.B PACS 품질경영시스템이 ISO 13485, IEC 62304, ISO 14971 등 적용 표준 및 내부 절차를 준수하는지 체계적으로 평가하기 위한 내부감사 절차를 규정한다.

## 2. 적용 범위

- QMS 전 프로세스 (설계, 개발, 검증, 변경관리, CAPA, 불만처리, 공급업체관리)
- 기술적 관리 활동 (소프트웨어 개발 프로세스, 사이버보안, 위험관리)
- WeRU.B PACS 운영 환경 (서버, Docker 서비스, 데이터 백업)

## 3. 용어 정의

| 용어 | 정의 |
|------|------|
| 내부감사 (Internal Audit) | 조직 내부에서 QMS 적합성을 평가하는 체계적 활동 |
| 감사원 (Auditor) | 감사를 수행할 역량을 갖춘 인원 (ISO 13485 교육 이수) |
| 부적합 (Nonconformity) | 요구사항 미충족 |
| 관찰사항 (Observation) | 부적합은 아니나 개선 기회가 있는 사항 |

## 4. 감사원 자격 요건

### 4.1 필수 자격
- ISO 13485:2016 교육 이수 (8시간 이상)
- 의료기기 소프트웨어 개발 경험 1년 이상
- 감사 대상 프로세스에 직접 관여하지 않는 인원 (독립성)

### 4.2 수석 감사원
- ISO 13485 내부감사원 과정 수료
- 감사 수행 경험 2회 이상

## 5. 연간 감사 일정

### 5.1 정기 감사 (연 2회)

| 차수 | 시기 | 감사 대상 프로세스 | 적용 표준 |
|------|------|-------------------|-----------|
| 1차 | 6월 | 설계관리(SOP-003), SW개발(SOP-005), V&V(TD-005) | IEC 62304, ISO 13485 §7 |
| 2차 | 12월 | 변경관리(SOP-007), CAPA(SOP-008), 불만처리(SOP-011), 공급업체(SOP-010) | ISO 13485 §8 |

### 5.2 특별 감사 (수시)

다음 사항 발생 시 수석 감사원이 특별 감사를 개시할 수 있다:
- MFDS 현장 심사 대비
- 중대 부적합 또는 부작용 보고 후
- 주요 제품 변경 (아키텍처 변경, SOUP 대규모 업데이트)
- 고객 불만 급증 (월 3건 이상)

### 5.3 2026년 감사 계획

## 6. 감사 수행 절차

### 6.1 감사 계획 수립 (감사 2주 전)

1. 수석 감사원이 감사 계획서를 작성한다:
   - 감사 목적, 범위, 기준
   - 감사 대상 프로세스 및 문서
   - 감사원 배정
   - 일정 (1~2일)
2. QA 책임자가 감사 계획서를 승인한다.
3. 감사 대상 부서에 감사 계획을 통지한다.

### 6.2 감사 준비 (감사 1주 전)

1. 감사원은 해당 프로세스의 SOP, 기록, 이전 감사 결과를 사전 검토한다.
2. 체크리스트를 작성한다 (적용 표준 조항별 확인 항목).
3. WeRU.B PACS 특화 확인 사항:
   - Docker 서비스 13개 가동 상태
   - PostgreSQL 40+ 테이블 정합성
   - API 340+ 엔드포인트 응답 상태
   - 감사 로그(`audit_logs`) 정상 기록 여부

### 6.3 감사 수행

1. 시작 회의: 감사 목적/범위/일정 확인
2. 증거 수집:
   - 문서 검토 (Git 이력, QMS 문서)
   - 시스템 확인 (서버 접속, API 테스트, 로그 점검)
   - 인터뷰 (담당자 면담)
3. 발견 사항 기록:
   - 부적합 (NC): 요구사항 미충족 → 시정조치 필요
   - 관찰사항 (OBS): 개선 기회 → 권고
4. 종료 회의: 발견 사항 공유, 시정조치 기한 합의

### 6.4 감사 보고서 작성 (감사 후 5영업일 이내)

감사 보고서에 포함할 항목:
- 감사 일자, 감사원, 대상 프로세스
- 감사 기준 (적용 표준 조항)
- 발견 사항 (NC/OBS 목록)
- 시정조치 요청 (CAR) 및 기한
- 종합 평가 (적합/조건부 적합/부적합)

### 6.5 시정조치 및 후속 관리

1. 부적합 사항은 SOP-008(CAPA)에 따라 시정조치를 수행한다.
2. 시정조치 기한: 경미 30일, 중대 15일.
3. 감사원이 시정조치 완료를 확인하고 종결한다.
4. 미종결 건은 차기 감사 시 추적한다.
