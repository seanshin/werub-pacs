## 1. 적용 범위

본 품질매뉴얼은 의료영상저장전송장치(PACS) 소프트웨어의 설계, 개발, 배포, 유지보수에 적용되는 품질경영시스템(QMS)을 기술한다.

### 1.1 제품 범위
- 의료 영상(DICOM) 저장, 전송, 조회 소프트웨어
- 웹 기반 영상 뷰어 (WeRU.B Viewer, OHIF v3.12 기반)
- DICOM 비표준 영상 검증 및 정규화 엔진
- 판독 워크플로우 관리 (워크리스트, 리포트, 템플릿)
- QC 기능 (Study 병합/분리, 태그 수정, 익명화)
- 감사 로그 및 보안 관리

### 1.2 제외 범위
- AI 진단 보조 기능 (별도 3등급 인허가 대상, WeRU.B PACS 내에서는 "보조 참고" 기능으로만 제공)
- 하드웨어 제조
- 임상시험 (2등급 PACS는 불필요)

### 1.3 규제 분류
- 의료기기 등급: **2등급** (의료영상저장전송장치)
- 인허가: MFDS (식품의약품안전처)
- 소프트웨어 안전 등급: **IEC 62304 Class B**

## 2. 품질 방침

> **의료 영상 데이터의 정확성, 무결성, 가용성을 보장하여 환자 안전과 진단 품질에 기여한다.**

### 2.1 품질 목표 및 KPI

| # | 품질 목표 | KPI | 목표치 | 측정 주기 | 담당 |
|---|----------|-----|--------|-----------|------|
| Q1 | 소프트웨어 결함 최소화 | Critical/High 결함 건수 | 0건 | 월 | 개발팀 |
| Q2 | 시스템 고가용성 | 서비스 가동률 | 99.5% 이상 | 월 | IT |
| Q3 | DICOM 표준 적합성 | 비표준 영상 정규화율 | 90% 이상 | 분기 | 개발팀 |
| Q4 | 보안 취약점 신속 대응 | Critical/High CVE 패치 소요 시간 | 48시간 이내 | 수시 | 보안 |
| Q5 | 고객 불만 신속 대응 | 초기 대응 시간 준수율 | 95% 이상 | 월 | QA |
| Q6 | API 성능 유지 | p95 응답 시간 | < 200ms | 월 | 개발팀 |
| Q7 | 테스트 커버리지 유지 | 단위 테스트 커버리지 | 85% 이상 | 릴리스 | QA |
| Q8 | 내부감사 완수 | 연간 감사 계획 이행률 | 100% | 연 | QA |

### 2.2 KPI 모니터링 및 보고

- 월간: Q1~Q6 KPI를 QA 책임자가 집계하여 개발팀 공유
- 분기: Q3, Q5 집중 분석 보고
- 연간: 경영검토 회의에서 전 KPI 종합 보고 (§6.2 참조)

- QMS 성과 및 개선 필요성을 경영진에 보고
- 규제 요구사항 인식을 조직 전체에 전파

### 4.2 설계 관리 (SOP-003)
- 설계 입력: 요구사항 명세서(TD-001, 340+ endpoints)
- 설계 출력: 설계 명세서(TD-002), 아키텍처 설계서(TD-003)
- 설계 검토: PDCA Gap Analysis (Match Rate >= 90%)
- 설계 검증: 단위/통합/시스템 테스트 (TD-005)
- 설계 확인: 사용적합성 평가 (UE-001)
- 설계 이관: 프로덕션 배포 + 24시간 모니터링

### 4.3 소프트웨어 개발 (SOP-005)
- IEC 62304에 따른 소프트웨어 생명주기 관리
- PDCA 사이클 기반 품질 게이트 (Match Rate >= 90%)
- Git 버전 관리 + Design History File 추적
- 18 Phase 개발 완료 (340+ API endpoints), AI 모델 29개 (의료 13종, 범용 16종)

### 4.4 변경 관리 (SOP-007)
- 모든 변경사항 DHF에 기록 (CHG-NNN)
- 영향 분석 필수 (위험관리, 기능, 성능)
- Critical 변경 시 위험관리 파일 업데이트 (RM-002)

### 4.5 시정예방조치 (SOP-008)
- 부적합 사항 발견 시 CAPA 개시
- 근본 원인 분석 → 시정 조치 → 효과성 검증
- 30일 내 시정조치 완료 (경미: 60일)

## 6. 경영 책임

### 6.1 경영 의지

대표이사는 다음 사항을 보장한다:
- QMS 수립 및 유지를 위한 자원 배분
- 품질 방침 및 품질 목표의 수립과 전파
- 규제 요구사항 준수 보장
- 경영검토의 정기 수행

### 6.2 경영검토 절차

**주기**: 연 1회 (12월) + 필요 시 수시

**입력 사항**:
1. 내부감사 결과 (SOP-009)
2. 고객 불만 및 부작용 현황 (SOP-011, SOP-012)
3. CAPA 현황 (SOP-008)
4. 품질 목표 KPI 달성 현황 (§2.1)
5. 프로세스 모니터링 결과
6. 공급업체(SOUP) 평가 결과 (SOP-010)
7. 규제 변경 사항
8. 이전 경영검토 후속 조치 상태

**출력 사항**:
1. QMS 및 프로세스 개선 결정
2. 규제 요구사항 대응 계획
3. 자원 배분 결정
4. 품질 목표 수정 (필요 시)

**기록**: 경영검토 회의록 → `docs/regulatory/records/` 보관 (5년)

### 6.3 2026년 경영검토 일정

| 일정 | 유형 | 주요 안건 |
|------|------|-----------|
| 2026-06 | 중간 검토 | MFDS 인허가 진행 현황, 1차 내부감사 결과 |
| 2026-12 | 정기 검토 | 연간 QMS 성과, 2차 내부감사, 차년도 계획 |
