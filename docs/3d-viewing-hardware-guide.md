# 3D 영상(MPR/VRT) 판독 워크스테이션 하드웨어 가이드

**작성일**: 2026-06-06
**대상**: 3D(MPR/MIP/VRT) 기능 사용 클리닉의 판독 PC 사양 선정
**관련**: `docs/03-analysis/3d-pacs-capability-review.md`

---

## 0. 핵심 원칙: 렌더링은 **클라이언트(판독 PC)**에서

WeRU.B Viewer(OHIF/Cornerstone3D)는 **클라이언트 사이드 렌더링** — 영상은 판독자의 **브라우저+GPU**에서 그려진다. 따라서 **서버 사양이 아니라 판독 PC 사양**이 3D 성능을 좌우한다.

```
[Orthanc 서버] --(DICOMweb 픽셀데이터 전송)--> [판독 PC 브라우저: WebGL/GPU 렌더링]
                                                  ↑ 여기 하드웨어가 3D 성능 결정
```

---

## 1. 기능별 요구 사양

| 기능 | GPU | RAM(브라우저) | 비고 |
|------|-----|------|------|
| **2D 스택 뷰** | 통합그래픽 OK | 4GB+ | 단일 슬라이스 표시 |
| **MPR** (3평면 재구성) | WebGL2 (통합그래픽 가능, 외장 권장) | **8GB+** (전체 볼륨 메모리 적재) | 균일 슬라이스 간격 필요 |
| **MIP/MinIP** | WebGL2 | 8GB+ | 볼륨 기반 |
| **3D VRT** (볼륨 렌더링) | **외장 GPU 권장** (전용 VRAM 2GB+) | **16GB+** | GPU 집약적 |

> **메모리 주의**: 볼륨 로딩은 **시리즈 전체를 브라우저 메모리에 적재**한다. 예) 흉부 CT 500슬라이스 × 512×512 × 2바이트 ≈ 260MB(원본) + 렌더링 버퍼. 대용량(1000+ 슬라이스, 박슬라이스 CT)은 16GB+ 필요.

---

## 2. 권장 워크스테이션 등급

| 등급 | 용도 | CPU | RAM | GPU | 비고 |
|------|------|-----|-----|-----|------|
| **기본** (2D 위주) | CR/DX/US 판독 | i5/Ryzen5 | 8GB | 통합그래픽 | MPR 제한적 |
| **표준** (MPR) | CT/MR + MPR | i7/Ryzen7 | 16GB | 통합그래픽 또는 GTX1650급 | 권장 기본 |
| **고급** (VRT) | 3D 볼륨 렌더링 | i7/Ryzen7+ | 32GB | RTX3050+ (VRAM 4GB+) | 대용량 CT·VRT |

- **브라우저**: Chrome/Edge 최신 (WebGL2 필수). 콘솔에서 `CornerstoneRender: using GPU rendering` 확인 → GPU 가속 정상.
- **디스플레이**: 의료영상 판독은 고해상도(2MP+) 모니터 권장 (하드웨어 가이드 범위 외).

---

## 3. GPU 없는/저사양 클리닉 폴백

GPU가 약하거나 없는 환경:
- **2D 스택 + MPR(소프트웨어)** 까지는 동작하나 느릴 수 있음.
- **VRT는 비활성/비권장** — 사용자에게 2D/MPR 판독 안내.
- WebGL2 미지원 브라우저 → `showCPUFallbackMessage`(현재 false) 정책 검토.
- 향후 옵션: 서버사이드 렌더링(별도 아키텍처, v2.0 검토).

---

## 4. 전제·제약 (3D 동작 조건)

- **볼륨 데이터**: 다중 슬라이스(≥수십 장) CT/MR.
- **균일 슬라이스 간격**: `strictZSpacingForVolumeViewport: true`(config) → **비균일 간격 시리즈는 볼륨 렌더 불가**(2D 스택만). 비균일 영상이 잦은 환경은 §본 정책 완화 검토(`docs/03-analysis/3d-pacs-capability-review.md` G4).
- **전송 대역폭**: 볼륨 로딩은 시리즈 전체 다운로드 → 병원 LAN 권장. `maxNumberOfWebWorkers: 3`(병렬 디코딩).

---

## 5. 도입 체크리스트

- [ ] 판독 PC가 **표준 등급 이상**(16GB RAM, WebGL2 GPU)인가
- [ ] Chrome/Edge 최신 + WebGL2 활성
- [ ] (VRT 사용 시) 외장 GPU(VRAM 4GB+) 장착
- [ ] 콘솔 `using GPU rendering` 확인
- [ ] 대상 CT/MR이 **균일 슬라이스 간격**인가 (비균일 시 볼륨 렌더 제한)
- [ ] 병원 LAN 대역폭 (대용량 볼륨 전송)

> **요약**: 3D는 서버가 아닌 **판독 PC**가 좌우한다. MPR은 16GB+통합그래픽, **VRT는 외장 GPU + 32GB**를 권장한다. GPU 미흡 환경은 2D/MPR로 운영한다.
