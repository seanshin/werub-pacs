## 1. v2.0 에픽 (통합·우선순위)

우선순위 P0(핵심·선행) → P2(대규모·후행). 규모 S/M/L/XL. 의존성 명시.

| 에픽 | 내용 | 규모 | 우선 | 의존성 |
|------|------|:---:|:---:|------|
| **A1. XDS-I.b Phase 1 (제출)** | 현 XDM *생성*을 넘어 **ITI-41 Provide&Register**로 실제 Registry/Repository 제출. affinity domain 정의 | L | **P0** | A2(PIX) |
| **A2. PIX/PIXm (I002 MPI)** | 환자 식별자 교차참조 — **EMR 인증 I002 갭과 동일 스코프**(통합 확정). ITI-9/ITI-8 또는 PIXm(FHIR) | L | **P0** | affinity domain |
| **A3. XCA-I 교차 커뮤니티** | 다기관 영상 질의/조회(Cross-Community) | XL | P2 | A1·A2 |

## 2. 권장 착수 순서 (의존성 기반)

```
Phase 1 (선행 인프라)     : A2(PIX/MPI) → A1(XDS-I 제출)   ← EMR I002 갭 동시 해소
Phase 2 (플랫폼 기반)     : B1(멀티테넌시 RLS)             ← 모든 다기관 기능의 토대
Phase 3 (가치 빠른 단독)  : C1(HTJ2K) · C2(VRT 튜닝) · A4(Gazelle)  ← 의존성 적음, 병행 가능
Phase 4 (확장)            : B2/B3(SaaS·클라우드) · A3(XCA-I) · B4(페더레이션)
Phase 5 (대규모 신영역)   : D1(엔터프라이즈) · C4(모바일앱)
```

**권고 1순위**: **A2(PIX/MPI) + A1(XDS-I Phase1 제출)** — 사유:
1. **EMR 인증 I002 MPI 갭과 동일 스코프**(2건을 1로 통합) → 규제·상호운용 동시 달성.
2. 멀티사이트(B4)·XCA-I(A3)·엔터프라이즈(D1) 모두의 **공통 선행 인프라**.
3. 현 XDS-I *export*(v12.2)·ATNA 어댑터(v12.4) 자산 재사용 — 점진 확장.

**병행 권고**: **C1(HTJ2K)** — 의존성 없고 대용량 CT 체감 개선 즉효, 코덱 단위 격리 작업.

## 3. v2.0 진입 전 결정 필요 (사용자/사업)
- **멀티테넌시 시점**: 유료 고객 확보 전 선투자 vs 첫 다기관 계약 후 착수(B1 XL 규모).
- **MFDS 인허가 상태**: 25문서 행정 심사 결과 — 상용화 게이트.
- **affinity domain 운영 주체**: XDS Registry를 누가 호스팅(기관 컨소시엄/WeRU.B 중앙).
- **GPU 직결 인프라**(C3): 수요·비용 정당화 시점.
