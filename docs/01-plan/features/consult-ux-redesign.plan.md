# 의뢰/자문 UX 리디자인 기획서

> **Summary**: 외부 판독 의뢰·세컨드 오피니언·피어 리뷰의 UX를 전문 의료 시스템 수준으로 고도화
>
> **Project**: OpenPACS (WeRU.B)
> **Version**: v7.7+
> **Date**: 2026-05-20
> **Status**: Draft

---

## 1. 현재 문제점

| 문제 | 상세 |
|------|------|
| 모달 기반 입력 | 작은 모달 안에 모든 필드가 밀집 — 의료 의뢰에 부적합 |
| 상태 추적 어려움 | 의뢰/자문 상태를 별도 페이지에서만 확인 가능 |
| 판독 화면과 분리 | 판독 중 의뢰하면 컨텍스트(영상, 소견)가 전달 안 됨 |
| 외부 포털 단조 | 법적 동의 → 의견 작성이 단순 폼 — 전문적이지 않음 |
| 이력 부족 | 해당 Study의 의뢰/자문 이력이 판독 화면에 안 보임 |

---

## 2. 리디자인 방향

### 2.1 핵심 원칙

1. **판독 화면 내 통합** — 모달이 아닌 슬라이드 패널로 확장
2. **컨텍스트 전달** — 현재 소견/결론을 의뢰 시 자동 첨부
3. **타임라인 기반 이력** — Study별 의뢰/자문/피어 리뷰 이력을 시간순 표시
4. **전문 포털** — 외부 전문의가 사용하기 편한 3단계 워크플로우

## 3. 판독 화면 리디자인

### 3.1 현재 구조

```
┌─────────────────────────────────────────┐
│ 판독 리포트                              │
│ [소견] [결론] [권고]                      │
│ [임시 저장] [서명] [더보기 ▾]             │
│                     ├─ 피어 리뷰 요청     │  ← 모달
│                     ├─ 세컨드 오피니언     │  ← 모달
│                     └─ 외부 판독 의뢰     │  ← 모달

## 4. 외부 포털 리디자인

### 4.1 현재 → 변경

| 현재 | 변경 |
|------|------|
| 단순 폼 | 3단계 가이드 워크플로우 |
| 텍스트 약관 | 카드형 동의 항목 + 체크박스 | 
| textarea만 | 구조화된 의견 폼 (소견/결론/권고) |
| 뷰어 링크만 | 영상 썸네일 미리보기 포함 |

## 5. 의뢰 관리 페이지 리디자인

### 5.1 통합 관리 대시보드

현재 의뢰(`/consults`)와 자문(`/second-opinion`)이 분리되어 있음.
→ **통합 협진 관리** 페이지로 병합.

```
┌──────────────────────────────────────────────┐

│                                              │

│ └─────┘ └─────┘ └─────┘ └─────┘             │

│ [전체] [외부 판독] [세컨드 오피니언] [피어 리뷰] │
│                                              │
│ ┌──────────────────────────────────────────┐ │
│ │ 🟡 외부 판독 의뢰 — 대기                  │ │

│ │ 긴급도: 일반 · 의뢰자: dr.kim             │ │

## 6. 구현 순서

| # | 작업 | 규모 | 우선 |
|---|------|:----:|:----:|
| 1 | 판독 화면: 더보기 모달 → 사이드 패널 전환 | 대 | High |
| 2 | 판독 화면: Study별 협진 이력 타임라인 | 중 | High |
| 3 | 의뢰 폼: 단계별 가이드 + 소견 자동 첨부 | 중 | High |
| 4 | 외부 포털: 3단계 리디자인 (랜딩→동의→의견) | 중 | High |
| 5 | 통합 협진 관리 페이지 (의뢰+자문+피어리뷰) | 중 | Medium |
| 6 | 포털 영상 썸네일/미리보기 | 소 | Low |
| 7 | 승인 기관 관리 Admin UI | 소 | Low |
