# OpenPACS v2.0 — 임상 실무 활용을 위한 기능 개선 기획서

> **작성일**: 2026-05-09
> **기반 버전**: v1.0.0 (44 API, OHIF Viewer, Orthanc, FastAPI)
> **목표**: 실제 의료진(영상의학과, 임상의, 기사)이 일상 업무에서 사용 가능한 수준으로 개선

---

## 1. 현재 상태 분석

### 1.1 v1.0.0에서 되는 것
- Orthanc DICOM 서버 (C-STORE 수신, DICOMweb)
- OHIF Viewer (영상 조회, W/L, 줌, 스크롤)
- 비표준 DICOM 검증 엔진
- JWT 인증 + RBAC
- 판독 리포트 API (CRUD + 서명)
- QC API (Study 병합/분리)
- AI 추론 파이프라인 (mock)
- 워크리스트 API

### 1.2 스크린샷 기반 현재 문제점

| 문제 | 상세 | 영향 |
|------|------|------|
| **영어 UI** | OHIF 전체 영어 — 한국 의료진이 사용 불편 | 높음 |
| **HospitalRun 연동 없음** | 환자 클릭 → 영상 조회 흐름이 끊김 | 높음 |
| **판독 워크플로우 UI 없음** | API만 존재, 뷰어 내에서 리포트 작성 불가 | 높음 |
| **로그인 연동 없음** | HospitalRun과 PACS 별도 로그인 필요 | 보통 |
| **환자 매칭 없음** | HospitalRun 환자 ↔ PACS 환자 자동 연결 안 됨 | 높음 |
| **검사 오더 연동 없음** | HospitalRun에서 검사 오더 → PACS 워크리스트 자동 생성 불가 | 높음 |
| **판독 상태 미표시** | Study List에 판독 대기/완료 구분 없음 | 높음 |
| **긴급 영상 알림 없음** | 긴급 검사 도착 시 실시간 알림 미작동 | 보통 |
| **인쇄/내보내기 UI 없음** | API만 존재, 버튼/메뉴 없음 | 보통 |
| **환자 정보 표시 부족** | Study List에 한글 환자명이 깨지거나 비어있음 | 보통 |

## 2. v2.0 목표

### 2.1 핵심 목표
**"HospitalRun에서 검사 오더 → PACS 영상 수신 → OHIF에서 판독 → 리포트 작성 → HospitalRun에서 결과 확인"**

이 전체 흐름이 끊김 없이 동작해야 한다.

### 2.2 대상 사용자별 시나리오

**임상의 (외래/병동)**
1. HospitalRun 환자 차트 열기
2. "영상 검사" 탭 클릭 → PACS 영상 목록 표시
3. 영상 클릭 → OHIF 뷰어에서 바로 열림
4. 판독 리포트 확인

**영상의학과 전문의 (판독의)**
1. PACS 로그인 (또는 HospitalRun SSO)
2. 판독 대기 목록 확인 (긴급 우선 표시)
3. Study 클릭 → OHIF 뷰어 열림
4. 영상 판독 후 뷰어 내에서 리포트 작성
5. 전자 서명 → 의뢰의에게 알림

**영상의학과 기사**
1. 워크리스트에서 오늘 검사 목록 확인
2. 모달리티에서 촬영 → PACS 자동 수신
3. 영상 품질 확인 → 승인/반려
4. 환자 정보 오류 시 QC 수정

## 3. 개선 기능 명세

### 3.1 HospitalRun ↔ PACS 통합

#### 3.1.1 환자 영상 탭 (HospitalRun 측)
- HospitalRun 환자 상세 화면에 **"영상 검사"** 탭 추가
- Patient ID 기반으로 PACS DICOMweb 조회
- Study 목록 표시 (날짜, 모달리티, 설명, 판독 상태)
- Study 클릭 → OHIF 뷰어 새 탭으로 열기
  ```
  /viewer/?StudyInstanceUIDs={uid}&PatientID={pid}
  ```

#### 3.1.2 검사 오더 → 워크리스트 연동
- HospitalRun에서 영상 검사 오더 생성 시 → OpenPACS 워크리스트 API 자동 호출
- 오더 정보: 환자ID, 환자명, 모달리티, 검사부위, 의뢰의, 임상정보
- 워크리스트 상태가 HospitalRun 오더 상태에 반영

#### 3.1.3 판독 결과 연동
- 판독 리포트 서명 시 → HospitalRun 환자 차트에 결과 자동 표시
- 리포트 내용: 소견, 결론, 판독의, 서명일시
- 긴급 소견 시 HospitalRun 알림

#### 3.1.4 SSO (Single Sign-On)
- HospitalRun JWT 토큰으로 PACS API 자동 인증
- 별도 PACS 로그인 불필요
- 역할 매핑: HospitalRun 의사 → PACS Physician, 영상의학과 → Radiologist

### 3.2 한국어 UI

#### 3.2.1 OHIF 한국어화
- Study List 헤더: Patient Name→환자명, MRN→환자번호, Study Date→검사일 등
- 도구 모음: Window/Level→밝기/대비, Zoom→확대, Pan→이동, Length→길이 등
- 메뉴/다이얼로그 전체 한국어 번역
- OHIF i18n 시스템 활용 (커스텀 locale 파일)

#### 3.2.2 날짜/시간 한국 형식
- 검사일: YYYY-MM-DD (2026-05-09) 또는 YYYY년 MM월 DD일
- 시간: 24시간 형식 (KST)
- 환자 생년월일: YYYY.MM.DD

#### 3.2.3 한글 환자명 개선
- Specific Character Set 자동 감지 및 표시
- 초성 검색 지원 (ㅎㄱㄷ → 홍길동)
- OHIF Study List에서 한글 정렬 지원

### 3.3 판독 워크플로우 UI

#### 3.3.1 판독 대기 목록 (Worklist View)
- OHIF Study List 상단에 **판독 상태 필터** 추가
  - 전체 | 판독 대기 | 판독 중 | 판독 완료 | 긴급
- 각 Study 행에 상태 아이콘 표시
  - 🔴 긴급 (STAT)
  - 🟡 판독 대기
  - 🔵 판독 중 (잠금)
  - 🟢 판독 완료
  - ⚠️ 비표준 DICOM 경고

#### 3.3.2 뷰어 내 리포트 패널
- OHIF 우측 사이드바에 **리포트 작성 패널** 추가
- 영상을 보면서 동시에 리포트 작성 가능
- 구성:
  - 임상 정보 (읽기 전용, 오더에서 가져옴)
  - 소견 (Findings) — 자유 텍스트
  - 결론 (Impression) — 자유 텍스트
  - 권고 사항 — 선택
  - 긴급도 선택 (정상/비긴급 이상/긴급)
  - 이전 검사 참조 버튼
  - 서명 버튼
- 키보드 단축키: Ctrl+Enter → 서명

#### 3.3.3 이전 검사 비교
- 현재 Study와 동일 환자의 이전 Study 자동 로딩
- 좌: 현재 / 우: 이전 레이아웃
- 슬라이스 동기화, W/L 동기화

#### 3.3.4 템플릿 기반 구조화 리포트
- 모달리티/검사부위별 리포트 템플릿
- 자주 쓰는 문구 즐겨찾기 (단축어 입력)
- 템플릿 예시:

| 템플릿 | 필드 |
|--------|------|
| Chest PA | 폐야, 심장, 종격동, 흉막, 골격 → 결론 |
| Brain CT | 뇌실질, 뇌실, 뇌수조, 두개골, 부비동 → 결론 |
| Abdomen CT | 간, 담낭, 췌장, 비장, 신장, 장관, 림프절 → 결론 |
| Knee MRI | 전방십자인대, 후방십자인대, 반월판, 관절연골, 골수 → 결론 |

### 3.4 긴급 영상 알림

#### 3.4.1 실시간 알림
- 새 영상 도착 시 → 뷰어/HospitalRun에 팝업 알림
- 긴급 검사(STAT) → 소리 알림 + 화면 깜빡임
- AI가 이상 소견 감지 시 → 판독의에게 즉시 알림
- 판독 완료 시 → 의뢰의에게 알림

#### 3.4.2 알림 채널
- 웹 푸시 (브라우저 Notification API)
- OHIF 내 알림 패널
- HospitalRun 내 알림
- 이메일 (선택)

### 3.5 영상 품질 관리 UI

#### 3.5.1 QC 대시보드
- 오늘 수신된 영상 목록 (시간순)
- 검수 상태: 미검수 / 승인 / 반려
- 환자 정보 오류 표시 (비표준 DICOM 검증 결과 연계)
- QC 통계: 일일 검사 수, 반려율, 장비별 오류율

#### 3.5.2 원클릭 QC 작업
- 환자 정보 수정 → 폼 팝업 → 수정 → 자동 반영
- Study 병합/분리 → 드래그 앤 드롭 UI
- 반려 → 사유 선택 → 재촬영 요청 자동 발송

### 3.6 Admin 관리 포털

#### 3.6.1 대시보드
- 오늘 통계: 검사 수, 판독 수, 판독 대기, 긴급 건
- 주간/월간 트렌드 차트
- 장비별 검사 건수
- 스토리지 사용량

#### 3.6.2 사용자 관리 UI
- 사용자 목록/등록/수정/비활성화
- 역할 변경
- 접근 로그 조회

#### 3.6.3 DICOM 노드 관리 UI
- 모달리티 장비 등록 (AE Title, IP, Port)
- 연결 테스트 (C-ECHO)
- 라우팅 규칙 설정
- AI 자동 트리거 규칙 설정

### 4.1 프론트엔드 신규 개발

| 구성 | 기술 | 설명 |
|------|------|------|
| **Admin Portal** | Next.js 15 | 관리 대시보드, 사용자 관리, QC, 통계 |
| **판독 패널** | React (OHIF Extension) | OHIF 뷰어 내 리포트 작성 사이드바 |

| **한국어화** | OHIF i18n | ko-KR 번역 파일 |

### 4.2 백엔드 추가 API

| API | 용도 |
|-----|------|
| `GET /api/v1/patients/{pid}/studies` | 환자별 영상 목록 (HospitalRun 연동) |
| `GET /api/v1/studies/{uid}/read-status` | 판독 상태 조회 |
| `POST /api/v1/orders` | 검사 오더 → 워크리스트 자동 생성 |
| `GET /api/v1/notifications` | 알림 목록 |
| `POST /api/v1/notifications/acknowledge` | 알림 확인 |
| `GET /api/v1/dashboard/stats` | 대시보드 통계 |
| `GET /api/v1/dashboard/trends` | 주간/월간 트렌드 |
| `GET /api/v1/qc/pending` | QC 미검수 목록 |
| `POST /api/v1/templates` | 리포트 템플릿 CRUD |
| `GET /api/v1/templates/{modality}` | 모달리티별 템플릿 |

### 4.3 HospitalRun 수정 범위

| 파일/모듈 | 변경 내용 |
|-----------|----------|
| `apps/web/app/patients/[id]/` | 영상 검사 탭 추가 |
| `apps/web/components/pacs/` | PACS 영상 목록 컴포넌트 (신규) |
| `apps/api/src/orders/` | 검사 오더 시 PACS 워크리스트 API 호출 |
| `apps/web/components/notifications/` | PACS 알림 연동 |

## 7. 성공 기준

| 기준 | 목표 |
|------|------|
| HospitalRun → 영상 조회 | 환자 차트에서 2클릭 이내로 영상 열기 |
| 판독 리포트 작성 | 뷰어 내에서 영상 보면서 리포트 작성/서명 완료 |
| 한국어 UI | OHIF 주요 UI 90% 이상 한국어화 |
| 판독 TAT | 판독 대기 목록 → 리포트 서명까지 흐름 완성 |
| 긴급 알림 | 긴급 검사 도착 후 10초 이내 판독의 화면에 알림 |
| QC | 영상 도착 → 품질 검수 → 승인/반려 워크플로우 완성 |
| 모바일 | 임상의가 모바일에서 영상 조회 + 리포트 확인 가능 |
