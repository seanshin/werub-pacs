## 2. 판독의 (Radiologist) 가이드

### 2.1 판독 시작
1. 대시보드에서 **"판독 시작"** 클릭 또는 **판독** 메뉴 선택
2. 판독 큐에서 환자 선택 → **"판독"** 버튼 클릭
3. 듀얼 모드: **"WeRU.B 뷰어"** 버튼으로 별도 창에 영상 뷰어 열기

### 2.2 판독 화면 구성
- **환자 정보 바**: 환자명, 모달리티, 검사일, SLA 시간
- **AI 툴바**: 영상 분석, 이전 비교, SOAP, 감별진단
- **템플릿 & 단축어**: 접기/펼치기, 클릭 시 자동 적용
- **소견/결론/권고**: 텍스트 입력 영역 + 음성 입력

### 2.3 AI 활용
- **영상 분석**: MedGemma가 소견/결론 자동 생성
- **이전 비교**: 동일 환자 이전 검사와 자동 비교
- **SOAP 요약**: 소견 기반 SOAP 노트 생성
- **감별진단**: ICD 코드 포함 감별진단 목록

### 2.4 판독 서명
- **임시 저장**: `Ctrl+S`
- **서명**: `Ctrl+Enter` 또는 "서명 완료" 버튼
- 서명 시 주치의에게 자동 알림 발송

### 2.5 협진/의뢰
- 판독 화면 하단 **"협진/의뢰"** 버튼
- 세컨드 오피니언, 외부 판독 의뢰, 피어 리뷰 요청 가능

### 2.6 판독 통계
- `/pacs-admin/reading/stats` 에서 TAT 분석 확인
- 판독의별/모달리티별 평균 판독 시간, 시간대별 분포

## 3. 방사선사 (Technologist) 가이드

### 3.1 워크리스트
- **워크리스트** 메뉴에서 오늘 예약 검사 확인
- HIS에서 오더 수신 시 자동 등록

### 3.2 재촬영 요청 처리
1. **재촬영** 메뉴에서 요청 목록 확인
2. 상태 필터: 요청됨 → 승인 → 스케줄 → 완료
3. **승인/거부** 버튼으로 처리 (코멘트 가능)

### 3.3 정규화
- **정규화** 메뉴 → "설정" 탭에서 알고리즘 확인
- 배치 업로드: `/pacs-admin/normalization/batches`
- 리뷰 대기: medium/risky 항목 검토 후 승인

### 3.4 응급
- **응급** 메뉴에서 대기 환자 현황 확인
- 대기 시간 자동 계산 및 색상 표시

## 4. 관리자 (Admin) 가이드

### 4.1 대시보드
- 통합 현황: 판독 대기, SLA, 재촬영, HIS, AI, 스토리지
- SLA 위반 건수 실시간 표시
- 30초마다 자동 갱신

### 4.2 사용자 관리
- **사용자** 메뉴에서 계정 생성/수정/삭제
- 역할 배정: admin, radiologist, resident, physician, technologist, researcher

### 4.3 SLA 설정
- **SLA** 메뉴 → "설정" 탭
- 모달리티별 경고/위험 임계값 (분 단위) 설정
- 에스컬레이션 규칙: 알림, 자동 재배정, 상급자 에스컬레이션
- 자동 스케줄러: 5분 간격 SLA 체크 + 10분 간격 자동 해결
- "지금 체크" 버튼으로 수동 실행

### 4.4 AI 모델 관리
- **AI** 메뉴에서 모델 상태/활성 관리
- GPU AI 서버 연결 상태 + API Key 확인
- 자동 판독 초안 설정: `/api/v1/ai/auto-draft/config`

### 4.5 HIS 연동
- **HIS** 메뉴에서 수신 요청 이력 조회
- 유형별 필터: 재촬영, 취소, 추가촬영, 긴급판독, 환자정보, 임상정보, 일정변경

### 4.6 Webhook 설정
- API: `PUT /api/v1/webhooks/config`
- 지원 유형: Slack, Microsoft Teams, Generic JSON
- 이벤트 필터 + 최소 긴급도 설정
- 테스트 발송: `POST /api/v1/webhooks/test`

### 4.7 정규화 설정
- **정규화** 메뉴 → "설정" 탭
- 8개 알고리즘 활성/비활성 토글
- 위험도별 처리: Safe(자동), Medium(검토), Risky(수동 승인)
- 트리거: 수신 시 자동 / 야간 배치 스케줄

### 4.8 알림
- 네비게이션 바 🔔 벨 아이콘으로 실시간 알림 확인
- WebSocket 자동 수신 + 30초 폴링

### 4.9 다크 모드
- 네비게이션 바 🌙 아이콘 클릭
- 시스템 설정 자동 감지 (첫 접속 시)
- 판독실 저조도 환경에 최적화

### 4.10 감사 로그
- **감사로그** 메뉴에서 전체 접근/수정 이력 조회
- 의료법 5년 보존 요건 준수

## 6. FAQ

### Q. 판독 서명 후 수정할 수 있나요?
A. 서명된 판독은 잠금 상태가 됩니다. 수정이 필요한 경우 관리자에게 잠금 해제를 요청하세요. 모든 수정은 감사 로그에 기록됩니다.

### Q. AI 분석 결과를 임상에 사용할 수 있나요?
A. 현재 AI 모델은 **연구 목적 전용**입니다. 임상 판독의 근거로 사용할 수 없으며, 최종 판단은 의료진의 책임입니다.

### Q. SLA 알림이 오지 않아요.
A. 관리자에게 SLA 설정 → 에스컬레이션 규칙 활성화 여부를 확인하세요. Celery beat 스케줄러가 동작 중이어야 합니다.

### Q. 외부 기관에 판독 의뢰하려면?
A. 판독 화면 → "협진/의뢰" → "외부 판독 의뢰" 선택 → 기관/이메일 입력 → 전송. 포털 링크가 자동 발송됩니다.

### Q. 다크 모드가 적용되지 않는 페이지가 있어요.
A. 일부 하위 페이지에서 다크 모드가 완벽히 적용되지 않을 수 있습니다. 점진적으로 개선됩니다.
